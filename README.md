Reusable engineering skills.

## Available skills

### complexity-convergence-audit

Repository-wide audit and cleanup method for reducing accidental complexity in medium-scale software systems.

Focus areas include:

- unnecessary architectural layers and abstractions
- security over-engineering
- audit infrastructure
- observability and telemetry
- microservice and deployment boundaries
- migration and compatibility scaffolding
- excessive tests and implementation-coupled tests
- CI duplication and over-blocking quality gates
- ADR and repository-directive extraction
- final convergence review and stop criteria

See [complexity-convergence-audit/SKILL.md](complexity-convergence-audit/SKILL.md).
